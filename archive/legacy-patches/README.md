# Arquivo de aplicadores legados

Esta pasta preserva materiais gerados durante as versões visuais V6–V11.

- `backups/` mantém os arquivos `.before-*` com o caminho original abaixo de `src/`.
- `root-assets/` contém folhas de estilo e arquivos auxiliares que estavam soltos na raiz.

Esses itens são históricos e não participam do build. Não os use como fonte ativa sem comparar com a versão atual em `src/`.
